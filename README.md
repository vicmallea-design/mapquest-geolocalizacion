# Laboratorio DEVASC: Script de Geolocalización y Rutas

Este repositorio contiene el desarrollo del software de cálculo de rutas y métricas de viaje mediante APIs REST en Python.

## Archivos del Proyecto
- `mapquest_parse-json_enhanced.py`: Script principal en Python para el cálculo de distancia (km/millas), tiempo estimado, combustible e indicaciones paso a paso.
- `README.md`: Documentación del proyecto.

## Requisitos Previos
- Python 3.x
- Librería `requests` (`pip3 install requests`)

## Instrucciones de Uso
1. Ejecutar el script desde la terminal:```bash
   python3 mapquest_parse-json_enhanced.py
